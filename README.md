# 搶答派對

諮詢科餐敘用的手機即時搶答遊戲。題目直接顯示在每個人的手機上，答得又快又對分數越高，每場總分第一名拿小禮物。

- 同仁加入：https://kayin0821-cell.github.io/quiz-party/
- 主持＋出題：https://kayin0821-cell.github.io/quiz-party/host.html

## 主持流程

1. 用主持帳號登入，在「我的題庫」編輯題目並儲存。
2. 按「開新場次」，選題數、要不要打亂順序，產生 PIN 碼和 QR code。
3. 讓同仁掃 QR code，或把「複製邀請文字」貼到群組。
4. 想出題時按「出第 N 題」，並喊一聲「出題囉！」。時間到或全員作答後會自動公布答案。
5. 最後一題公布後按「揭曉總排名」。冠軍會記在首頁的「得獎紀錄」，發完獎勾「已發」。

## 小提醒

- 活動前一天打開網站一次，避免資料庫因閒置暫停。
- 同仁沒收到題目時，重新整理頁面就會回到同一場，分數還在。

# 小天使票選（vote/）

2026 諮詢科小天使票選：最佳 Duty 1 名、最佳同事 5 名，全科 79 人每人每項一票，不記名，11/14 前截止。

- 投票：https://kayin0821-cell.github.io/quiz-party/vote/
- 主持：https://kayin0821-cell.github.io/quiz-party/vote/admin.html（用 sup 登入）

## 主持流程

1. 主持頁「投票碼」→ 複製到 Excel 或列印小紙條，私下發給每位同仁。
2. 「複製投票邀請」貼到 M+ 群組。
3. 「還沒投票」名單可以用來提醒。同仁只要輸入 8 位數投票碼，不用選名字。
4. 聚餐前按「截止投票」，才看得到結果。
5. 聚餐時按「進入揭曉模式」，一個一個公布。播到最後一頁時，同仁的投票頁會自動變成得獎名單（不含票數）。
6. 按「重新開放投票」，同仁頁會收起得獎名單、回到投票畫面。

選票不記投票人和時間，主持帳號也查不到誰投給誰。
